How this page is built

  1. GitHub Actions (public repo) requests releases/latest from the private olai-core repo using the OLAI_PAT secret — the token exists only as an encrypted Actions env var, never in this site's code or bundle.
  2. The 188.6 MB flagship pack is downloaded; its first megabyte becomes pack-head.bin.
  3. alai-engine is compiled from source and run over a fixed prompt set (English + Tamil); outputs land in samples.json.
  4. The olai format crate is cross-compiled to wasm32-unknown-unknown and shipped to your browser.
  5. Everything deploys to GitHub Pages. You are reading the result.
